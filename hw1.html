Exercise 1.1.1

Consider a floating-point set $\mathbb{F}$ defined by (1.1.1) and (1.1.2) with $d=4$.

(a) How many elements of $\mathbb{F}$ are there in the real interval $[1/2,4]$, including the endpoints?

With $d=4$, we have $z\in[0\colon2^d-1=15]$ and thus $f\in2^{-d}z=\{z/16\mid\forall z\}$.

With $e=-1$, we have $(1+f)2^e=\{16/32,17/32,\dots31/32\}$, 16 elements in $[1/2,1)$.

With $e=0$, we have $(1+f)2^e=\{16/16,17/16,\dots31/16\}$, 16 elements in $[1,2)$.

With $e=1$, we have $(1+f)2^e=\{16/8,17/8,\dots31/8\}$, 16 elements in $[2,4)$.

Add $4=(1+0/16)2^2$ to get 49 elements total in the real interval $[1/2,4]$.

(b) What is the element of $\mathbb{F}$ closest to the real number 1/10? (Hint: Find the interval $[2^n,2^{n+1})$ that contains $1/10$, then enumerate all the candidates in $\mathbb{F}$.)

$e=-4$ generates FPs on $1/10\in[1/16,1/8)$.

With $e=-4$, we have $(1+f)2^e={16/256,17/256,\dots,31/256}$, of which $26/256=(1+10/16)2^{-4}$ is closest.

(c) What is the smallest positive integer not in $\mathbb{F}$? (Hint: For what value of the exponent does the spacing between floating-point numbers become larger than 1?)

$e=4$ generates $\{16,17,\dots31\}$, every integer on $[16,32)$.

$(1+0/16)2^5=32$, and $(1+1/16)2^5=34$, skipping $33$. $33$ is the smallest positive integer not in $\mathbb{F}$.

Exercise 1.1.2

Prove that (1.1.5) is equivalent to (1.1.6). This means showing first that (1.1.5) implies (1.1.6), and then separately that (1.1.6) implies (1.1.5).

(1.1.5) states $\frac{|\text{fl}(x)-x|}{|x|}\leq\frac{2^{n-d-1}}{2^n}=\frac{1}{2}\epsilon_M$, and (1.1.6) states $\text{fl}(x)=x(1+\epsilon)$ for some $|\epsilon|\leq\frac{1}{2}\epsilon_M$.

(1.1.5) $\to$ (1.1.6):

$$\begin{align*} &\frac{|\text{fl}(x)-x|}{|x|}=|\frac{\text{fl}(x)-x}{x}|\leq\frac{1}{2}\epsilon_M\\ \to&\,-\frac{1}{2}\epsilon_M\leq\frac{\text{fl}(x)-x}{x}\leq\frac{1}{2}\epsilon_M\\ \end{align*}$$

Now assume $x>0$.

$$\begin{align*} \to&\,\text{fl}(x)-x\leq x\frac{1}{2}\epsilon_M\\ \to&\,\text{fl}(x)\leq x(1+\frac{1}{2}\epsilon_M) \end{align*}$$

Now if we set $\text{fl}(x)=x(1+\epsilon)$ where $\epsilon\leq\frac{1}{2}\epsilon_M$, we get exactly (1.1.6) for positive $\epsilon$.

If we instead assume $x<0$,

$$\begin{align*} \to&\,-x\frac{1}{2}\epsilon_M\geq\text{fl}(x)-x\\ \to&\,x(1-\frac{1}{2}\epsilon_M)\geq\text{fl}(x)\\ \end{align*}$$

Now if we set $\text{fl}(x)=x(1+\epsilon)$ where $-\epsilon\leq\frac{1}{2}\epsilon_M$, we get exactly (1.1.6) for negative $\epsilon$.

We can combine these into the given $|\epsilon|\leq\frac{1}{2}\epsilon_M$.

(1.1.6) $\to$ (1.1.5):

$$\begin{align*} &\text{fl}(x)=x(1+\epsilon),|\epsilon|\leq\frac{1}{2}\epsilon_M\\ \to&\,-\frac{1}{2}\epsilon_M\leq\epsilon\leq\frac{1}{2}\epsilon_M\\ \end{align*}$$

Now assume positive $\epsilon$.

$$\to\,\text{fl}(x)\leq x(1+\frac{1}{2}\epsilon_M)$$

We can walk back the algebraic manipulation shown in (1.1.5) $\to$ (1.1.6) to reach $\frac{|\text{fl}(x)-x|}{|x|}\leq\frac{1}{2}\epsilon_M$.

If we instead assume negative $\epsilon$,

$$\to\,x(1-\frac{1}{2}\epsilon_M)\geq\text{fl}(x)$$

We can again walk back the algebraic manipulation to reach the same $\frac{|\text{fl}(x)-x|}{|x|}\leq\frac{1}{2}\epsilon_M$.

As (1.1.5) $\to$ (1.1.6) and (1.1.6) $\to$ (1.1.5), they are equivalent.

Exercise (1.2.1)

Use (1.2.6) to derive the relative condition numbers of the following functions appearing in Table 1.2.1.

(a) $f(x)=x^p$

$$\kappa_f(x)=|\frac{x(x^p)'}{x^p}|=|\frac{xpx^{p-1}}{x^p}|=|\frac{xp}{x}|=|p|$$

(b) $f(x)=\ln x$

$$\kappa_f(x)=|\frac{x(\ln x)'}{\ln x}|=|\frac{x*1/x}{\ln x}|=\frac{1}{|\ln x|}$$

(c) $f(x)=\cos x$

$$\kappa_f(x)=|\frac{x(\cos x)'}{\cos x}|=|\frac{-x\sin x}{\cos x}|=|x\tan x|$$

(d) $f(x)=e^x$

$$\kappa_f(x)=|\frac{x(e^x)'}{e^x}|=|x|$$

Exercise (1.2.8)

Generalize (1.2.13) to finding a root of the $n$​th degree polynomial $p(x)=a_nx^n+\cdots+a_1x+a_0$, and show that the relative condition number of a root $r$ with respect to perturbations only in $a_k$ is $\kappa_r(a_k)=|\frac{a_kr^{k-1}}{p'(r)}|$.

(1.2.13) states:

$$\kappa_f(a)=|\frac{a}{r_1}\cdot\frac{dr_1}{da}|=|\frac{ar_1}{2ar_1+b}|=|\frac{r_1}{r_1-r_2}|$$

For finding the conditioning of the leading coefficient of some quadratic $at^2+bt+c=0$ on some root $f(a)=r_1$.

For a general $n$​th degree polynomial of the form $p(x)=a_nx^n+\cdots+a_1x+a_0$, we can follow the same steps outlined in the textbook.

Differentiating $a_nr_1^n+\cdots+a_kr_1^k+\cdots+a_1r_1+a_0$ implicitly with respect to $a_k$, holding all other $a_i$ fixed, yields

$$\begin{align*} &\frac{d}{da_k}(a_nr_1^n+\cdots+a_kr_1^k+\cdots+a_1r_1+a_0)\\ =\,& a_n(n)r_1^{n-1}\frac{dr_1}{da_k}+\cdots+(r_1^k + a_k(k)r_1^{k-1}\frac{dr_1}{da_k})+\cdots+a_1(1)r_1^0\frac{dr_1}{da_k}\\ =\,& \frac{dr_1}{da_k}(a_n(n)r_1^{n-1}+\cdots+a_k(k)r_1^{k-1}+\cdots+a_1)+r_1^k\stackrel{\text{SET}}{=}0\\ \to\,& \frac{dr_1}{da_k}=\frac{-r_1^k}{a_n(n)r_1^{n-1}+\cdots+a_1} \end{align*}$$

Now that we have a generalized equation for $\frac{dr_1}{da_k}$ and indeed any $\frac{dr}{da_k}$, we can find the condition number of a root $r$ with respect to perturbations only in $a_k$.

$$\kappa_r(a_k)=|\frac{a_k(dr/da_k)}{r}|=|\frac{a_k}{r}\cdot\frac{-r_1^k}{a_n(n)r_1^{n-1}+\cdots+a_1}|=|\frac{a_kr^{k-1}}{p'(r)}|$$

The function

$$x=\cosh(y)=\frac{e^y+e^{-y}}{2}$$

$$y=\text{acosh}(x)=-\ln(x-\sqrt{x^2-1}).$$

$$\begin{align*} \kappa_f(x_1)=\kappa_f(\frac{e^4+e^{-4}}{2})&=4\\ \kappa_f(x_2)=\kappa_f(\frac{e^8+e^{-8}}{2})&=8\\ \kappa_f(x_3)=\kappa_f(\frac{e^{12}+e^{-12}}{2})&=12\\ \kappa_f(x_4)=\kappa_f(\frac{e^{16}+e^{-16}}{2})&=16 \end{align*}$$

import numpy as np

def cosh(y):
    return (np.exp(y) + np.exp(-1 * y)) / 2

def f(x):
    return -1 * np.log(x - np.sqrt(x ** 2 - 1))

for i in range(1, 4 + 1):
    y = 4 * i
    x = cosh(y)
    f_x = f(x)
